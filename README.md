# GFI Timer

An instructor-focused fitness class timer for iPhone and iPad. Classes are
defined as static data, while one reusable timer engine handles phases, rounds,
exercises, rests, progress, and playback controls.

The app will be an offline-capable React/TypeScript PWA deployed to GitHub
Pages. No backend or App Store installation is required for the first version.

## Project status

Planning is complete; implementation has not started.
